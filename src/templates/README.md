# Templates

Page-level layout that arranges organisms. Imported into `@layer templates`.

Planned:
- `collection.css` — Collection / Category / Tag page grid + sidebar layout
- `pdp.css` — PDP gallery + buy-box + pairs-well arrangement (incl. mobile)
- `cart.css` — cart page (if a full-page cart is used alongside the drawer)

Templates own layout/placement only; visuals come from the organisms/molecules
they contain. Fluid rules per DESIGN-SYSTEM.md §4 (rem/clamp, auto-fill grids,
single-column collapse ≤768px).
